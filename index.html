01 — About the Project

Security audits
without installing anything.

A web-based utility that inspects the security configuration of any public domain by analyzing HTTP response headers, cryptographic SSL/TLS parameters, and core DNS records, directly from your browser.

The execution layer runs completely serverless on Cloudflare Pages Functions, leveraging Cloudflare's DNS-over-HTTPS API to fetch SPF, DMARC, and MX records, alongside Qualys SSL Labs API for infrastructure certificate validations.

HTTP Security Headers HSTS, CSP, X-Frame-Options, X-Content-Type, Referrer-Policy
DNS Infrastructure SPF, DMARC, and MX validation for anti-spoofing resilience
Verified SSL/TLS Labs Real-time grading via Qualys, evaluation of cipher suites and expiration
IP Geolocation & PDF Export Server ASN, country, and city mapping with downloadable summaries
